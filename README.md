# PP_TP2_53423
# Trabajo Práctico 2 - Paradigmas de Programación (POO)
**Universidad Tecnológica Nacional - Facultad Regional Mendoza**

## Descripción del Proyecto
Este repositorio contiene la resolución del Trabajo Práctico N° 2 de la asignatura Paradigmas de Programación. El proyecto evoluciona el sistema de gestión de eventos universitarios aplicando conceptos avanzados de POO en Java, tales como el manejo de excepciones, la persistencia de datos, el uso de genéricos, clases anidadas y programación concurrente.

## Contenido de la Resolución
* **Ejercicio 1:** Implementación de persistencia de objetos mediante serialización (lectura y escritura de archivos `.dat`) y gestión de errores mediante excepciones chequeadas personalizadas (`CupoExcedidoException`) manejadas con bloques `try-catch-finally`.
* **Ejercicio 2:** Incorporación de la interfaz `Certificable`, simulando herencia múltiple de tipos para dotar de nuevas capacidades transversales a las actividades concretas (`Taller` y `Curso`).
* **Ejercicio 3:** Utilización de métodos parametrizados acotados (`<T extends Actividad>`) y wildcards (`<? extends Actividad>`) para el filtrado fuertemente tipado de colecciones y el cálculo polimórfico de costos.
* **Ejercicio 4:** Implementación de clases anidadas miembro (`TicketDeAcceso` dentro de `Inscripcion`) y programación concurrente utilizando hilos (`EnvioTicketsThread`) para simular el procesamiento en segundo plano sin bloquear el hilo principal.
